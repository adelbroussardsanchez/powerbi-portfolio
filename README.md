# Power BI Portfolio
## Overview

This repository contains a collection of Power BI dashboards, supporting data models, and related artifacts demonstrating data modeling, reporting, and analytics capabilities. It highlights financial reporting, customer-level analysis, and project management monitoring, along with associated DAX, M code, and model optimization practices.

## Repository Structure

-**Financial Packet:**
Core financial model for Income Statement, Balance Sheet, and Cash Flow reporting. Includes month-end reporting, period comparisons, and hierarchical statement presentation.

-**Sales Dashboard:**
Extends the core financial packet to include customer-level sales and profitability analysis. Supports Gross Profit reporting, customer ranking, sales contribution analysis, and drill-down by customer.

-**Project Management Dashboard:**
Operational project tracking and resource workload analysis. Integrates task-level detail with Microsoft Teams updates for backlog, blocked, and completed task tracking, KPI reporting, and project performance measurement.

-**DAX Measures:**
Contains example DAX measures used in each dashboard grouped into categories.

-**M Code:**
Stores Power Query scripts for data extraction, transformation, and loading. Includes source references, transformation steps, and any custom logic applied.

-**Tabular Editor:**
Contains scripts and metadata edits applied via Tabular Editor, including calculation groups, hierarchies, and model optimization notes.

-**Recordings:**
Video recordings of dashboard interactions, demonstrating key functionality, filters, and scenarios.

-**Screenshots:**
Static images of dashboards for reference and documentation, showing key visuals and insights.

## Key Features

Standardized financial reporting and period comparisons

Customer-level profitability and sales tracking, including top customers by Gross Profit and sales variables (incentives, brokers, freight)

Project management tracking integrated with Microsoft Teams

Optimized data models using reusable DAX measures and calculation groups

Transparent ETL processes via M code

Reusable model structures and layouts for consistent reporting

## How to Use

Explore each folder to review the dashboards, measures, M code, and Tabular Editor scripts.

Use the README in each folder for detailed explanations of measures, transformations, or modeling choices.

Watch recordings or view screenshots for visual context and understanding of dashboard interactions.

## Notes

Measures and model logic for the financial packet are designed to be reusable across clients.

All dashboards follow consistent naming conventions and layout structures for clarity.

Customer and project analyses are layered on top of core financial and operational data to maintain accuracy.
